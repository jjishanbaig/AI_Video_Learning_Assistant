# AI Video Learning & Interview Assistant

A local-first learning workspace built with React + Vite + Tailwind and FastAPI. Gemini powers summaries, source-grounded chat, quizzes, flashcards, and mock interviews. SQLite stores the library and generated study material.

## Features
- YouTube URL ingestion using available public transcripts (transcript access varies by video).
- Upload video for Gemini multimodal analysis; supported by Gemini File API and your account's model limits.
- Upload PDF, DOCX, PPTX, TXT, and Markdown notes.
- Summary and detailed study notes.
- Chat grounded in the selected source text, with a clear fallback when the source doesn't contain an answer.
- Generate quizzes and flashcards.
- Mock interviews: question-by-question practice and AI feedback.
- Export generated text to PDF, DOCX, or Markdown.
- Persistent library and basic learning analytics.

## Requirements
- Python 3.10+ recommended (3.11/3.12 are good choices).
- Node.js 18+.
- Gemini API key from Google AI Studio: https://aistudio.google.com/apikey
- Internet connection for Gemini calls and YouTube transcript retrieval.

## Start on Windows
### 1. Configure backend
Open a terminal in the project root:
```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```
Edit `backend/.env` and set `GEMINI_API_KEY=your_key_here`. Do not commit or share this file.

Start the API:
```powershell
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
API docs: http://127.0.0.1:8000/docs

### 2. Start frontend in a second terminal
```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```
Open http://localhost:5173

## Start on macOS/Linux
Backend:
```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# edit .env and set GEMINI_API_KEY
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```
Frontend in another terminal:
```bash
cd frontend
npm install
npm run dev
```

## Notes and limitations
- This is a runnable starter app, not a production deployment. It has no multi-user authentication; keep it on your own computer and do not expose the API publicly as-is.
- YouTube transcripts are not available for every video, language, or region. The app reports when transcript retrieval fails; upload a permitted video file or paste a transcript instead.
- Gemini video processing depends on API availability, supported MIME type, file size, model access, quota, and billing/free-tier limits. Large videos may take longer or need trimming.
- Source-grounded chat uses stored extracted text. If source text is incomplete, answers can be incomplete too.
- The API key stays in the backend `.env`; it is never sent to the browser.
- Exported PDF and DOCX files are generated by the backend.
